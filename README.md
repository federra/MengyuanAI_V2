## v0.14：五步创作工作流

- 仅调整创作工作台：主导航为创意→故事→剧本→分镜→成品导出。分场仍可在剧本编辑中进入；分镜阶段提供关联资产、视频素材与生成、配音素材和导出入口。Skill中心、渠道、收益数据与业务逻辑不变。
- 创意页集中项目名称、视频类型、风格、画幅和故事Skill，一句话生成多个候选故事。使用已配置文本API真实生成，未配置/失败时不伪造故事。候选只进入方案区，不覆盖当前正文；方案封面为类型装饰，不伪装生成图。
- Project JSON新增可选videoType、storyPlans、selectedStoryId，无D1迁移；旧项目兼容。最多12个候选，每次模型返回1–4个。选择方案前确认替换故事，保持剧本/媒体和ID，已有镜头标记待复核。故事可另存版本、比较、删除非当前候选。
- 故事/剧本/分场支持编辑、TXT/MD导入预览确认、阅读预览。确认故事进入剧本，剧本可生成分镜，原有JSON分镜导入仍在导演工具栏。未新增DOCX/PDF解析或富文本排版，正文保持可保存的纯文本。
- 各阶段右侧导演助手提供对应建议、Skill选择、要求输入，调用原有修改预览/勾选/关联应用流程。导演模型上下文只传当前故事，不附带所有候选。
- 分镜保留组合行、对白、统一提示词、人物/道具/场景/服饰/声音、站位图单镜生成、视频模型入口、自定义首帧和上一镜截帧。站位图入口去重。
- 成品导出新增启用镜头缩略图、逐镜画面预览、入点/片段结束控制、素材准备统计、可点击画面/配音/字幕/BGM轨道。预览是按镜头浏览画面，不含音轨混音或完整时间轴播放，不等同已渲染MP4。仍可导出JSON/SRT/完整剪辑包，FFmpeg本地渲染MP4；不伪造剪映草稿、云端渲染或收费/文件大小预测。
- 验证：core、creative、asset-library、frame-reference、models回归；TypeScript、应用源码lint、本地HTTP与生产构建。未执行浏览器视觉测试，也未调用收费生成服务。

## v0.13：独立 Skill 中心、两级渠道代理与收益账本

- 左侧新增 Skill 中心、收益中心、渠道代理；蓝白统计卡、标签导航、趋势/占比图、筛选列表与导出。
- Skill 中心复用导演助手的6种内置技能和项目级自定义技能，支持搜索、阶段筛选、跨项目复制、创建/编辑/删除、MD/TXT/JSON导入、JSON导出与直接调用。修改仍按原流程预览、勾选、应用、撤销；自定义技能随项目手动保存。
- 业务账本独立保存在 D1 `business_state`，每次操作自动保存；服务端计算、整数分金额、基点比例、版本比较写入，防止并发覆盖。新增迁移0002，保留已发布迁移。
- 两级代理由所有者人工登记，邀请码唯一、上级关系固定、最多两层，可停用/启用。佣金规则默认关闭且比例为0，不使用截图比例作为已批准规则。
- 所有者可登记实际收入的分类、日期、外部凭证、作品与关联代理。启用计佣后，直接代理获得直接佣金，有上级时其上级获得第二级佣金；按分向下取整。收入总额与代理应付佣金分列，避免重复计入收入。
- 历史佣金快照不随新规则改变。重复收入凭证（含已作废编号）被拒绝。未结算收入可说明原因后作废；待付款结算可取消并释放佣金；已登记付款不可直接取消或作废相关收入，退款仍需线下处理。
- 渠道结算支持创建、取消、查看关联收入以及录入线下付款凭证；付款凭证唯一。此功能不调用支付接口、不发起转账、不等同银行到账核验。
- 收益支持7/30/90天、全部及自定义期间、分类/状态/关键词筛选、CSV导出。代理与待付佣金总览明确为全期间；收入图表按收入日期统计。操作记录保留最近300条。
- 当前仍是仅所有者可访问的经营管理工作空间。没有代理自助登录、公开推广注册落地页、支付平台订单同步、自动分账、提现到账或多租户权限隔离；邀请码可复制用于人工业务登记，不虚构可访问的推广链接。
- 当前轻量账本上限500名代理、3000条收入及3000条结算，JSON按UTF-8限制1.5MB；规模化前迁移为规范化业务表和独立订单/退款流水。无演示金额、虚构收入或团队账号种子数据。
- 验证：`node tests/business.mjs`（金额边界、两层限制、重复凭证、历史规则快照、结算与作废、接口并发409）；原核心/资产/首帧/模型回归检查；TypeScript、应用源码lint、本地HTTP/API及生产构建。未执行浏览器视觉测试、真实支付或收费模型调用。

## v0.10 三类模型 API 接入

- 模型设置支持文本 Chat Completions、通用 Images Generations 文生图、Seedream 图生图与 Seedance/Ark 视频协议。可配置自定义兼容服务 HTTPS 基础地址、模型 ID、API Key、启用状态；文本可选择 thinking 开关或模型默认。不声称任意服务商协议均兼容。
- 服务端以 MODEL_ENCRYPTION_KEY 加密存储供应商密钥，GET 不回显密钥；更换地址必须重新填写密钥。旧 DEEPSEEK 配置仍作默认后备。当前站点仅限私有单用户，扩展多人前需增加项目/配置权限隔离。
- 故事、剧本、分镜、资产识别与导演 Skill 统一读取文本配置。资产图、镜头图、逐镜站位图、分镜视频已连接真实 API 提交流程。
- 视频首帧通过 R2 读取为 data URL 发送，支持独立首帧或多图参考模式。模型支持情况由具体服务商决定。每张参考图最多8MB、总计12MB、最多9张。
- D1 保存生成任务与供应商任务 ID；图片结果即时保存、视频通过“查询进度”获取并存入 R2。相同请求 ID 去重；不自动重试可能已扣费的提交。下载失败可再次查询/下载，图片 URL 失效或未知提交结果需人工核对服务商。刷新不会删除任务。
- 生成结果经预览和明确确认后应用到原资产/镜头，替换同类引用并提示保存。旧素材文件保留。没有部署后台调度器：视频状态由用户查询，临时 URL 应及时领取。
- 豆包浏览器插件：用户尚未提供插件名称、安装包或接口文档，当前明确标注待适配。官方 API 接入不代表已支持任意豆包插件。
- 验证：类型/lint、生产构建、原项目/首帧回归；tests/models.mjs 以模拟服务测试加密脱敏、输入校验、首帧载荷、重复提交、失败下载恢复及切换供应商保护；本地 API 检查。尚无用户服务商密钥，未执行付费模型实测或浏览器交互验收。
- 协议依据：[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[火山官方 SDK 视频任务](https://github.com/volcengine/volcengine-python-sdk/blob/master/volcenginesdkarkruntime/resources/content_generation/tasks.py)、[Seedream API](https://www.volcengine.com/docs/82379/1541523)。
