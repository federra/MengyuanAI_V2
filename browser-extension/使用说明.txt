# 豆包账号助手 0.6.0

桌面端 Helper 监听 127.0.0.1，按账号连接码鉴权；每个 Chrome user-data-dir 保存独立登录状态。管理服务用原子更新的 manager.json 保存账号与任务，账号备份不包含登录凭据或连接令牌。

账号分组、启停、每日提交上限、提交/成功/失败计数、积分和剩余次数来源标记、并发队列、20分钟默认结果超时、失败词配置、原视频任务重新获取均由 Helper 管理。关闭弹窗不停止任务，退出桌面程序或 Chrome 会中断观察。重启后待确认任务不自动重新提交。

扩展捕获匹配完整提示词的 fetch 生成请求，通过 requestId 和响应 videoId/messageId 绑定结果。只读原始素材字段，默认不修改生成请求。仅上传控件支持时填入参考图，并保留图号顺序；默认由用户确认附件、参数并提交。自动提交需要配置明确的参数与提交控件；有参考图时还需配置上传成功元素，数量精确匹配后才提交。未适配时停留待核对，不猜测上传完成。XHR 等未匹配的生成提交不会假记成功或回填。

原始下载字段映射参考 https://github.com/chuansd/doubao-international （README 声明 MIT），独立实现 image_ori_raw、original_media_info.main_url、no_watermark_url / original_url 提取和 get_play_info 查询。未复制其请求重试、强制15秒、URL水印参数改写或不明地址下载逻辑。不保证未知版本接口仍返回原始文件；未验证的源不会标成无水印。

积分读取需要配置唯一的页面元素选择器；未适配时显示未知，可手动校准。每日视频计数仅包括本工具观察到的提交，不声称覆盖账号全部历史。保留服务端权限和次数实际结果。

初次安装：更新桌面版，打开豆包插件，新增账号并打开对应 Chrome；在每个独立窗口 chrome://extensions 开启开发者模式，加载本目录；本人完成登录，在工作台确认已登录；回工作台再次点击“打开登录”即可自动连接。勾选参与任务的账号和分镜加入队列。完成后返回原分镜并提示保存。Chrome 未接入自动化测试环境，须在实际账号上验证控件和返回字段后再启用自动提交。

分镜直接生成与轮询（0.3.0）
- 分镜的“选择模型”可选择“豆包插件 · 分组轮询”，再选择账号分组。点击生成即加入该组队列并请求自动提交，不调用付费 API 渠道。
- 首次配置并验证提示词、参考图上传成功、生成按钮、运行中标记与空闲标记。空闲标记必须是确实仅在没有任务运行时出现的元素，不能使用整个页面或常驻按钮。未确认页面条件时不会自动提交。
- 每个账号只保留一个工作用豆包标签页。软件按组内最近分配顺序轮询，停用/离线/额度不足/忙碌账号不分配新任务。
- 原任务成功或失败后，还需连续两次页面空闲检测才允许下一个任务。超时、网络中断、工作台重启均保留原任务占用，不能自动跳过。
- 若原任务已经结束但回报丢失，可核对豆包页面后在任务页点“已核对原任务结束”；软件仍要求空闲检测通过。此操作不重新生成。
- 升级后在各 Chrome 配置的扩展管理页重新加载本扩展，再刷新豆包页面。旧扩展没有空闲状态检测，不会获得新任务。

AI 创作视频流程（0.4.0）
- 打开账号时进入 /chat/create-image。选择视频，再展开模型菜单，选择分镜指定模型；未指定使用插件默认（为空时 Seedance 2.0 Mini）。
- 展开比例与时长菜单，选择比例并设置 4–15 秒界面滑块（以实际滑块范围为准）。分镜参数优先，缺项使用插件默认。精确读回确认，超范围不截断，会员选项不可用不切换其他模型。
- 默认清晰度留空沿用豆包页面。截图菜单没有分辨率选项，若指定了清晰度则暂停准备并提示人工核对，不能假装已经设置成功。
- 任务记录支持状态与账号筛选、分页、参数来源、设置步骤、提交请求与视频标识、返回视频预览/下载及保存目录。重新获取只观察原任务，不重新生成。
- 暂停移出可运行队列并保留待办；恢复继续原任务。已提交任务持续接收返回结果。
- 同时支持 doubao.com 和 www.doubao.com。升级桌面版后，各账号 Chrome 扩展重新加载 0.4.0 并刷新豆包页。
- 页面自动流程已用模拟 DOM 检查；真实账号仍需验证上传成功、提交、运行/空闲选择器。若无法唯一识别控件则停止并记录原因，不用坐标盲点提交。

自动连接（0.5.0）
- 每个账号 Chrome 首次加载本插件一次，之后在工作台点击“打开登录”，会自动配对并打开豆包 AI 创作页，无需复制连接码。
- 配对通过本机 127.0.0.1 的一次性连接页完成，短码五分钟内有效、仅可使用一次；长期连接令牌不放入页面或浏览器地址。
- 已有豆包标签页时优先复用，不清空正在运行的任务。不允许将已连接其他账号的 Chrome 静默覆盖成当前账号。
- 豆包登录验证码仍由本人完成。连接工作台并不等于已登录豆包：完成登录后确认已登录，并勾选参与任务。
- 没有自动跳转时，展开工作台“连接帮助”，首次加载/重新加载插件，再点击打开登录。手动连接码仅为故障备用。

登录检测与账号核对（0.6.0）
- 工作台账号行点击“检测登录”。离线账号会打开独立 Chrome 并自动连接；在线账号检测当前豆包页。
- 检测可见登录入口和侧栏头像昵称：已登录、未登录、无法确认分别记录。检测不读取密码或 Cookie，不把插件连接成功当作豆包登录成功。
- 页面昵称无法唯一识别时，在生成设置 → 页面适配中配置“账号昵称元素”。检测最多等待页面加载并返回可解释的未确认状态。
- 检测完成后关闭对应豆包标签页（若为窗口最后一页则窗口关闭）；原任务运行、未发送草稿或页面繁忙时保留窗口。账号登录目录保留，下次打开无需重新创建账号。
- 浏览器标题和页顶显示固定“豆包序号 · 昵称/备注”，工作台列表同步。删除账号不会改变其他账号序号。
- 删除账号撤销参与任务与连接。活动/待核对任务的账号不允许删除；历史视频、记录与本机登录目录保留，仅此账号的等待任务无其他账号可用时取消。
- 升级后在每个账号 Chrome 中重新加载 0.6.0 扩展并刷新豆包页面。真实账号的 DOM 适配仍需实际核验。
