# 0.1.102

- 剧本工作区移除“分场编辑（可选）”。
- 分镜工作区仅保留组合视图，点击分镜序号打开轻量参数弹窗，不再进入独立详细视图。
- 分镜表按分镜序号、视频、提示词、台词、资产绑定、操作重排；压缩行高，资产用可点击的分类标签呈现，视频操作改为紧凑图标。
- 后续 Windows 安装包支持选择安装目录，首次安装默认创建桌面快捷方式。
- 分镜视频图标悬停显示功能提示，交换“删除当前视频”和“更多”位置；各行支持指针拖动排序及键盘微调，行间可插入，勾选后可确认批量删除；模型生成设置移至最右列。
- 模型选择独占一行，比例、时长与生成按钮并排对齐；桌面窗口支持自由调整大小，初始尺寸为屏幕留出可抓取的边缘。
- 剧本生成分镜按剧本片段处理，仅传入相关资产；每段校验通过后合并，输出长度不足时进一步拆分，完整结果返回前不修改项目。
- 创意、故事、剧本生成时中央显示半透明“AI努力生成中”提示；提示不阻挡页面操作和导航。
- 分镜视频预览扩大并填满预览区，视频操作按钮底部对齐；上一视频尾帧改为点击标签预览，模型列隐藏不可调整的比例并新增“详情”；直接生成视频免去第二次确认。增强鼠标拖拽排序与行间新增入口。

Windows 支持软件内更新，也可下载安装包；Mac 提供 Apple Silicon 和 Intel 应用包，保存项目并退出旧版后手动替换。
