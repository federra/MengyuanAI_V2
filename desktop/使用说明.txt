AI短片导演 · Windows 桌面测试版 0.1.56

开始使用
1. 解压整个文件夹，双击“AI短片导演测试版.exe”。请保留同目录的所有文件。
2. 软件会自动启动本地后端与数据库，不需要安装Node.js，也不需要手动启动网页服务。
3. 在“模型设置”中重新填写文本、图片、视频服务商API，然后测试连接。
4. 编辑项目后点击“保存”。关闭再打开，已保存的项目与素材会保留。

已有网页版项目
在网页版导出“项目JSON”，桌面菜单“工作台 → 导入项目JSON（文字与设定）”选择文件。
导入会创建新项目，保留文字、分镜、Skill与资产设定。JSON不包含素材文件，请重新上传图片、视频和音频。
只有分镜JSON时，在项目“分镜 → 导入分镜”中导入；支持episodes与兼容shots格式。

本地数据
菜单“工作台 → 打开本地数据目录”可以找到数据库和素材。
模型凭据保存在本地加密数据库中，加密密钥由Windows账户保护。
网页与桌面是独立数据环境，不会自动同步。不要删除用户数据目录或model-key.bin。
需要完整备份时，先退出软件，再备份整个“AI Director Desktop”用户数据文件夹；加密密钥与Windows账户关联。

测试范围
已集成当前五步创作工作流、Skill中心、资产中心、分镜导入、API接入、素材管理及导出界面。
每个视频段是一行分镜，内部子镜头不增加行数或重复累加时长。
AI生成仍需要网络、有效API和服务商额度；本测试包不预置服务商密钥。
豆包功能使用本机独立浏览器及扩展，首次使用需要本人登录豆包账号。
收益、渠道功能沿用工作台现有实现，不代表已接入真实支付或结算。

排查问题
“视图 → 刷新工作台”可重新加载；刷新前先保存。
“帮助 → 打开日志”查看本地服务启动情况，“视图 → 开发者工具”便于调试。
此包为未签名的内部测试版，Windows可能显示发布者未验证提示。

剪映草稿与目录设置（0.1.55）
作品导出 → 导出到剪映草稿：每次生成独立的新草稿，并复制素材到草稿的 Resources 目录。
画面按启用分镜顺序排列，保留视频裁切、配音与字幕时间段；配音替换对应分镜原声，背景音乐以20%音量循环。
缺少画面、素材下载失败或视频长度不足时停止导出并提示原因。不会用缺失素材生成一个看似成功的草稿。
剪映首页未刷新时，请保存剪映当前工程后重新打开剪映。新版剪映兼容性需实际打开草稿核对。
菜单“工作台 → 系统设置 · 文件位置”，或导出窗口中的目录设置，可以选择剪映草稿目录和项目文件目录。
剪映目录立即生效；更换项目目录请选择空目录，下次启动时迁移数据库和素材，原目录保留备份。
如另设项目目录，完整备份需同时备份该目录与 AI Director Desktop 用户数据目录（含 model-key.bin）。
source-project.json 是本次文字设定快照，不作为可跨电脑恢复的完整项目备份。剪映画面素材已独立复制。
草稿模板采用 Apache-2.0 开源格式模板，出处及许可证见 jianying-templates 文件夹。
