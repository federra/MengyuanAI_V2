# 模型设置、导航、分镜表头与记住登录

后续交付：上述优化已于2026-09-21随Windows 0.1.74发布，Mac渠道仍0.1.73。见 [发布记录](release-0.1.74.md)。下文源码阶段状态为实施时记录。

2026-09-21，用户确认模型设置方案A（四类页签＋配置展开列表），标语方案A（双行微型卡片）。仅源码及隔离预览，未递增版本、打包、发布或提交Git。

## 行为

- 模型设置：文本/图片/视频/音频页签显示数量；配置摘要含名称、模型ID、默认/启用状态，点击展开编辑，同页一次展开一个配置；新增自动展开。切换类别保留未保存编辑，不改变原有保存、密钥和模型调用协议。
- 导航：桌面可折叠成64px图标栏，已有顶部切换按钮控制展开；各入口有名称提示和可访问名称，系统设置改为扳手，与模型设置区分。折叠时隐藏品牌说明、标语正文和账号文字，保留退出入口。
- 标语：紧凑图标、主副标语、薄边框和主题渐变，沿用原文；折叠后隐藏。
- 分镜：表头文字全部居中，独立sticky层随页面下滑停留于表格顶部；表格横向滚动同步表头，保留全选和原编辑行为。
- 登录：默认不勾选“在此电脑记住账号和密钥”。只有中央登录成功后才保存；使用Electron safeStorage系统加密写入userData/remembered-login.enc，下次打开回填账号和密钥，不自动绕过中央授权。取消勾选立即清除保存记录；未勾选登录同样清除。安全存储不可用则不允许勾选；保存失败提示取消勾选后重试，绝不降级为明文。
- 新桌面模块 remembered-login.cjs 已加入Mac/Windows共享stage-runtime白名单。记住登录是当前系统用户、本机级偏好，不上传账号服务，不随安装包携带。
