# 项目回收站、深色剧本与台词布局（2026-10-05）

## 实现范围

- 项目中心每张已保存项目卡右上角增加三点菜单；删除弹窗提供“确认删除”和“取消”。确认后移入同页回收站，删除当前项目时先串行保存未保存修改。回收站可在30天内恢复完整项目，不自动打开恢复的项目。
- `projects.deleted_at` 记录服务端删除时间，保留原正文、资产、分镜及素材关联。删除、恢复均使用当前版本号做条件更新并递增版本，旧窗口保存不能复活回收项目或覆盖恢复后的版本。数据库迁移为 `drizzle/0004_project_trash.sql`，同步了 journal 和 snapshot；再次生成迁移无变更。
- 30天按30×24小时计算，到期边界不可恢复。读取项目或回收站时清理过期项目记录；登录后的页面每分钟及窗口重新获得焦点时检查。桌面关闭期间到期的项目在下次启动检查时清理。共享素材文件、独立资产中心和历史任务/使用记录不做物理删除，避免损坏其他项目引用。
- 删除成功后仅更新本地列表，不发起可能覆盖后续操作的冗余整表刷新；定时回收站请求使用序号，删除/恢复会使旧请求失效。清理和恢复的裁决以后台时间为准。

## 两处显示问题的原因

剧本正文 `.formatted-script` 固定白色背景、深色文字，绕过主题；现改用已有主题变量，阅读区域和输入区都跟随深浅模式。

台词列表采用有限高度的隐式网格行，条目多时每行被压缩。现使用不收缩的台词卡片和纵向滚动容器。已有 `lines` 在正文一致时直接返回，缺失说话人无法从显式标签补回；现优先显示原说话人，并从正文明确标签、角色名称/ID及声明别名恢复唯一说话人，保留台词ID、文本、声音和时间。多说话人条目提示待拆分；例如“妈妈”未明确绑定“年轻妈妈”时保留原称呼并提示待关联，避免猜错角色。
