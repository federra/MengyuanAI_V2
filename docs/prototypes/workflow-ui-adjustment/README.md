# 创作工作台低保真交互原型 V0.1

2026-09-23。独立评审稿，采用已讨论的“调整现有UI”方向。没有连接正式项目、数据库、账号、模型、豆包或导出服务，也没有修改业务代码。

## 打开方式

从项目根运行：

```sh
python3 -m http.server 4186 --bind 127.0.0.1 --directory docs/prototypes/workflow-ui-adjustment
```

访问 http://127.0.0.1:4186/ ，也可在浏览器直接打开本目录 index.html。HTML、CSS、JS全部本地，无外部依赖。推荐桌面窗口；窄窗口会隐藏业务侧栏并改为单列。原型不发布到外部网站。

## 审核范围

完整五阶段：**创意 → 故事 → 剧本 → 分镜（含素材制作）→ 成品导出**。成品导出与现有创作工作台能力一致，提供剪映草稿、分镜JSON、项目JSON、字幕SRT、完整剪辑包的交互演示；没有新增应用内MP4渲染。

流程总览提供三条入口：

1. **从一句idea开始**：清空演示产物，输入创意，配置X个候选；预览、采用并编辑故事，生成剧本和分镜结果后分别确认应用。
2. **导入成品故事**：粘贴正文或通过原生文件窗口选择TXT/MD，跳过候选生成，进入故事编辑。
3. **分镜示例**：载入六个镜头，四个视频占位、一个静态图占位、一个缺失画面，用于检查紧凑总览、展开编辑和导出检查。

分镜可展开、编辑、排序、勾选、批量模拟生成、切换表格。素材可选，默认文生视频模型允许无图；切换示意图生视频模型时，会检查已有参考。资产可编辑/清图；选择图片只记录名称，不读取或上传图片。任务支持模拟运行、成功或失败、预览、采用到原对象和返回对象。

成品导出包含顺序预览占位、镜头条、配音/BGM/字幕选择、缺项定位、导出确认和模拟完成。导出不会创建真实草稿、视频或项目文件；画面占位和播放轮播不代表真实视频合成。

顶部可以显示/隐藏交互批注，按页面记录审核意见并导出TXT。原型编辑与意见保存在浏览器专用localStorage键 `director-workflow-wireframe-v1`；切换演示场景只替换样本编辑，保留审核意见；刷新恢复本机草稿。正式系统的保存机制不因此改变。

## 评审建议

先看流程和主次操作，再看分镜摘要需要哪些信息、哪些控件应在展开层。最后确认素材分支和成品导出是否符合现有工作习惯。灰度配色和占位媒体用于评审结构，不代表最终视觉稿。

低保真范围：生成返回固定示例，不根据任意输入真实创作；经营/设置等无改动模块只标示原有位置；资产中心、复杂Skill设置、真实配音和媒体播放不在本轮交互展开范围。非完整正式系统复刻。
