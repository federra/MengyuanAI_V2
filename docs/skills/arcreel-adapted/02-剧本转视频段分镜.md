# 剧本转视频段分镜

## 一、用途与边界

把已确认剧本拆成可生成的视频段，并给出段内镜头、声音与整段提示词。可导入本系统，在剧本页“分镜 Skill”中选择后生成。仅输出候选结果，由用户预览确认。

本系统“一行分镜＝一个视频段＝一次视频生成输入”。段内切换景别或机位只新增子镜头，不自动新增工作台行。episodes 表示视频段数组，不是剧集数组；场次是地点与时间单元，也不等于视频段。

输入包括当前剧本片段、项目画幅、画风，以及实际提供的资产列表和用户要求。系统可能分批发送长剧本，只覆盖本次片段，不臆测前后文、不重写其他片段。资产列表也可能是局部列表，不能据此断言未列资产在全项目中不存在。

## 二、拆分与表演预算

1. 先读完本次片段，确定事件、说话顺序、时空变化和关键物件状态。已有剧本默认忠实转写，不改对白、不新增冲突或结局。
2. 按一次生成可连贯呈现的行动组织视频段；需要切换机位但时空和行动连续时，优先在段内安排子镜头。发生难以连续表现的时空变化、动作跨度或明确生成边界时再拆段。
3. 用户明确要求固定时长时遵循；否则按对白、动作、反应与停顿估算，不默认每段十秒。给出模型合法时长档位时优先满足档位；未给档位时只按平台范围规划，不宣称已验证模型可生成。每段 total_duration 必须为0.1至120秒。
4. 对白时长与动作可否并行都要考虑，不能让大量对白挤在极短子镜头中。新建分镜内容超时时可按语义边界增加视频段，保持对白原句和事件顺序；不要为固定段数删台词。既有分镜保真任务不自行改段数或时长，冲突由宿主支持的待确认机制说明。
5. 每段时间轴从0开始，子镜头连续无重叠、无空洞，最后 time_end 等于 total_duration。总时长只累计视频段，不把段内子镜头再累计一次；最多200个视频段。

## 三、画面、声音与资产

每个子镜头 camera 写景别、机位和运镜；visual 写可见主体、动作、空间关系与环境变化；audio 按发生顺序写说话人、原句、画外音和明确音效。画外音与画内对白分清；静音文字标明是画面文字，不能误作口播。不要用“他很难过”代替能表演的动作。

人物身份、服饰状态、道具持有者、行进方向和场景光照跨子镜头连续。每段 characters 与资产引用只包含实际视觉出现或使用的资产；只在对白中提及、不在画面出现的人物不强行出镜。声音保留其真实说话人。

已有资产按提供的名称与设定复用。只有提供了真实资产ID时才引用该ID；未提供已有资产ID时用名称表达，可省略可选ID数组，不伪造数据库ID。明确的新角色、场景、道具可用本次唯一的 @role_、@scene_、@prop_ 标识加入 missing_roles、missing_scenes、missing_props，正文对应写“中文名 ( @标识 )”。不要把未确定的外貌补成事实；服饰和声音信息在画面与 audio 中保留，不塞进错误的资产分类。

generation_prompt 是整段可独立使用的生成输入：写清项目画幅、画风、实际已知人物外观、场景、按秒排列的动作、对白和声音，不只堆资产ID。没有参考图信息时不写“见图1”；不把源文位置、分析过程或待确认备注写进生成指令。由于当前生成入口一次生成完整分镜，本技能同时补齐视觉提示词；后续精修可使用独立的视觉提示词 Skill。

## 四、输出契约

只输出一个纯JSON对象，无代码围栏、注释或说明。使用 director-storyboard/1.0，顶层 episodes 与 shots 不并存。以下为完整有效的最小结构示例；实际内容、段数和时长依据输入决定：

```json
{
  "schema_version": "director-storyboard/1.0",
  "episodes": [
    {
      "video_id": "01",
      "scene_name": "旧屋",
      "characters": ["林青"],
      "total_duration": 10,
      "shots": [
        {
          "shot_id": "01",
          "time_start": 0,
          "time_end": 4,
          "camera": "中景，固定机位",
          "visual": "林青穿蓝衣站在旧屋门边，抬手按住门板。",
          "audio": "环境声：门外雨声。"
        },
        {
          "shot_id": "02",
          "time_start": 4,
          "time_end": 10,
          "camera": "近景，缓慢推进",
          "visual": "林青的手仍按在门板上，侧头向屋内开口。",
          "audio": "林青：别开门。环境声：门外雨声持续。"
        }
      ],
      "generation_prompt": "16:9横屏，沿用项目画风。旧屋内，穿蓝衣的林青站在门边。0—4秒：中景固定机位，林青抬手按住门板；门外雨声。4—10秒：切近景缓慢推进，手的位置不变，林青侧头向屋内说：别开门。雨声持续。"
    }
  ]
}
```

video_id 在本次结果内唯一；shot_id 在所属视频段内唯一。source_refs 仅在能确认来源位置时填写。新资产各项必填：missing_roles 为 role_id、role_name、description；missing_scenes 为 scene_id、scene_name、description；missing_props 为 prop_id、prop_name、description。不需要新增资产时省略这些数组。

若输入是既有分镜且只要求保真整理，保留段顺序、数量、时长和全部内容；使用兼容顶层 shots 格式时，一项也必须是完整视频段，包含平台 duration、description、prompt 等字段，不能把上例两个子镜头当成两个顶层分镜。

输出前内部核对原文覆盖、对白归属、时间轴、名称引用及JSON完整性。规则是模型创作约束，实际导入仍需平台校验；不输出“保证生成成功”或“已应用”。
